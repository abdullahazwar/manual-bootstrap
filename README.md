# Personal Portfolio Website

Website portofolio pribadi yang dirancang dan dibangun secara mandiri menggunakan **Bootstrap murni** tanpa kerangka kerja (framework) JavaScript tingkat lanjut. Proyek ini dibuat untuk menampilkan profil, keahlian, serta proyek-proyek yang telah diselesaikan.

## Fitur Utama

- **Responsif Sepenuhnya**: Tampilan menyesuaikan secara otomatis di perangkat seluler, tablet, maupun desktop menggunakan sistem grid Bootstrap.
- **Navigasi Cepat**: Navbar interaktif 
- **Desain Modern**: Memanfaatkan komponen kustom Bootstrap seperti *card*, *badge*, *modal*, dan *form*.
- **Pesan Kontak Direct**: Form komunikasi langsung yang siap diintegrasikan dengan layanan pengiriman pesan.

## Teknologi yang Digunakan

- **HTML5**: Struktur dan konten dasar website.
- **Bootstrap v5.3**: Kerangka kerja CSS murni untuk tata letak responsif dan komponen UI.
- **Bootstrap Icons**: Ikon vektor untuk meningkatkan estetika antarmuka.
